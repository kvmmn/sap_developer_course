# SAP Developer Course Practice

This repository documents my practical progress through the **Startupistan SAP ABAP Developer Course**, a learning path focused on building the foundations needed to develop and work with SAP business systems.

It collects my public exercises and code samples across computer and digital literacy, development-environment setup, Git and GitHub, and later SAP/ABAP practice. Private course materials and personal study notes are intentionally kept outside the public Git history.

## Repository structure

- `startupistan-practice/` — Git and programming practice files
- `_exercises/` — space for upcoming public exercises

## Workflow

The repository uses a single Git history rooted at this directory. New public exercises and code samples should be committed here and pushed to `main` on GitHub.

Before committing:

1. Review `git status`.
2. Stage only files intended for public sharing.
3. Never commit credentials, environment files, personal documents, or licensed course material.

Local study materials are intentionally excluded from this public repository through `.gitignore`.
